Orchestrator + Capability Registry + Shared State

Wiele urządzeń.
Jeden ciągły workflow.

OneCore przenosi sprawdzony model AISITE: centralny orchestrator, dynamiczny routing po możliwościach urządzeń oraz wspólny stan sesji z event logiem.

Architektura Uruchom lokalnie

Live Topology

  • Phone - camera, push, mic
  • Laptop - editor, browser, sync
  • Desktop - GPU idle
  • Edge - kiosk mode active

Jak to działa

Control Plane

Orchestrator odbiera zadania i deleguje je do urządzeń lub agentów według polityk.

Capability Registry

Każde urządzenie publikuje capability set i heartbeat, więc routing jest dynamiczny.

Shared State + Event Log

Stan sesji trafia do wspólnego KV store, a każda akcja jest dopisywana do logu zdarzeń.

Fundament z poprzednich rozwiązań

To nie jest greenfield. Wykorzystujemy istniejące prymitywy z backupu: endpointy save/log oraz wzorzec orkiestracji z rejestrem możliwości.

MVP w tym repo

Dodany moduł onecore-mvp pokazuje rejestrację urządzeń, heartbeat, shared task state i handoff między urządzeniami.
