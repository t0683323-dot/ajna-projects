# Support

This document explains how to get help for Ajna Projects.

## Support Tiers

### 1) Community Support (Free)

Best-effort support from maintainers and community contributors.

- **GitHub Issues**: For bug reports and feature requests
- **GitHub Discussions** (if enabled): For usage questions and design conversations
- **Documentation**: First stop for setup and troubleshooting

**SLA**: No guaranteed response time.

### 2) Maintainer Review

Maintainers prioritize:

- Security issues reported via the channels in [SECURITY.md](./SECURITY.md)
- Regressions affecting core functionality
- Well-scoped issues with clear reproduction steps

**SLA**: Best effort; priority-based.

### 3) Commercial / Paid Support

If paid support is available for your organization, contact:

- partnerships@ajna-projects.org

Commercial support may include:

- Guaranteed response windows
- Architecture/design reviews
- Priority bug triage
- Migration and integration assistance

## How to Get Help Faster

When requesting support, include:

- Project/repository version or commit SHA
- Environment details (OS, runtime, dependency versions)
- Minimal reproduction steps
- Error logs, stack traces, and screenshots
- What you've already tried
